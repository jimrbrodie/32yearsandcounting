This site is built with [Jekyll](https://jekyllrb.com), a simple tool that turns plain text files into a fast, free website. It's hosted on [GitHub Pages](https://pages.github.com), which means there's no server to manage and no hosting bill.

## Adding a new blog post

Add a new file to the `_posts` folder named like `YYYY-MM-DD-your-title.md`, with a bit of front matter at the top:

```
---
title: "Your Post Title"
tags: [family]
author: "Jim"
excerpt: "One or two sentences describing the post."
---

Your story goes here, written in plain text or Markdown.
```

Commit it and push to GitHub &mdash; the site rebuilds automatically within a minute or two.

## Adding a new article

Same idea, but the file goes in the `_articles` folder instead. Articles are meant for longer, less time-bound pieces &mdash; family history, reflections, that sort of thing.

## The colours

Every colour on this site &mdash; the deep navy, the warm gold, the soft blush pink, the cream background &mdash; was pulled directly from the "32" logo, so the site always feels like a natural extension of the brand.
